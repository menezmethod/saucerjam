# Quantum Drift gauntlet contract

The parent agent is the sole **core integrator**. Builders edit only their assigned folder. Nobody but the integrator edits src/index.js, src/index.html, src/core/, src/styles/, shared/simulation.js, server/server.js, package.json, webpack.config.js, or root tests. No builder runs a production build or restarts port 8080. Submit core requests in your own folder/INTEGRATION.md. No commits, resets, stashes, or worktree cleanup (the working tree contains the preceding game rebuild).

## Wave 1 contracts

- Map builder owns `shared/maps/`. CommonJS `index.js` exports `MAPS`, `getMap(id)`, `MAP_ROTATION` (IDs). Maps keep `{id,name,subtitle,size,obstacles}`. Obstacles remain boxes `{type:'box',x,z,w,d,h,color}` or circles `{type:'cylinder'|'sphere',x,z,r,h,color}`. Three new maps: `foundry` (orbital industrial forge), `canopy` (overgrown research garden), `glacier` (polar relay). `classic` remains selectable. Collision spaces are flat, continuous, connected; structures in collision list are real gameplay cover. Cosmetic metadata `theme`, `districts`, `props`, `spawnPoints` allowed, documented. Avoid randomized layouts. Combat corridors >=4 units wide; bounded size 25–34.
- World builder owns `src/world/`. ES module `World.js` exports class `World` with constructor(scene, renderer), `build(map)`, `update(time,dt)`, `setTimeOfDay('day'|'dusk'|'night')`, `setShowcase(module)`, `dispose()`. It owns environment lights/floor/cover/scenery under a root group. Do not alter renderer's camera, ships, or app DOM. Return/use `root`. Cover exact collision dimensions; detailed geometry around it must not add invisible blockers. Rich peripheral silhouettes and landmarks, controlled visual hierarchy. Shared map metadata optional; fallback to id/theme. Three environments radically distinct. Sun shadows optional with bounded draw calls. Do not hide core cover. Map-only showcase = same world without ships handled by integrator.
- View builder owns `src/view/`. ES modules `CameraRig.js` and `ShipIndicators.js`. CameraRig(camera) exposes `update({player,aim,map,dt,lobby,view,zoom})`, `reset()`, `setPreset(name)`. player={x,z,angle,vx,vz}; view 0 default stable tactical follow, 1 chase legacy, 2 overview, 3 isometric. Zoom [0.7,1.5]. Favor clarity: stable heading by default, bounded look-ahead, avoid wasting screen beyond map. ShipIndicators(container) exposes `update({players,localId,camera,width,height,time})`, `dispose()`. Project HTML or canvas readable names + health above every living ship (including local), shield state, don't obscure aim. No imports from src/core.
- UI builder owns `src/interface/`. ES module `Interface.js` exports class Interface with constructor({maps,onMap,onLeaderboard,onPractice,onCamera,onZoom}), `update({state,player,mode,map,view,zoom})`, `setMaps(maps,selectedId)`, `showLeaderboard({scope,rows,playerId})`, `dispose()`. Import own CSS. Enhance existing DOM by adding map picker, polished leaderboard modal and readable match summaries; keep all existing IDs and button behavior working. May add DOM but do not rewrite existing HTML. Full scene/lobby screenshot via live app after integration; before that provide exported mount with safe defaults. Maps list of id/name/subtitle/theme. leaderboard rows={id,name,kills,deaths,wins,matches,score}; use safe DOM text, no invented player data outside explicit showcase.
- Ranking builder owns `server/rankings/`. CommonJS `index.js` exports `RankingStore` with constructor({filePath}), `recordRound({id,mapId,players,winnerId})`, `getLeaderboard({mapId,limit})`, `close()`. Persistent atomic JSON under configured server data directory; honor filePath:null memory mode. Human identities provided by integrator stable random profile token (server hashes), bots excluded. Deduplicate round IDs and concurrent flushes; deterministic ordering. Do not assume authentication/ranked anti-cheat stronger than implementation. Add tests in owned folder.

## Verification

`node scripts/verification/capture.cjs --url http://localhost:8080 --module arena --camera isometric --time dusk --map foundry --out docs/gauntlet/evidence/<owner>-r1` writes PNG and JSON with console/page errors, FPS/draw calls, screenshot config and state. Modes: arena, world, view, health, ui, effects. Run after integrator publishes dependencies. Inspect PNG using view_image; cite exact inspected paths. No visual claims before capture AND inspection.

Primary references: Nex Machina combat hierarchy, WipEout speed/industrial art direction, Battlerite anchored state and competitive round readability. No claim of equivalence between an arena and a city. Scores must explicitly state comparison and limitations. >=8.5 and zero runtime errors is the requested bar, not a preordained result. Iterate from the lowest independently scored area until all domains clear 8.5; no predetermined round cap. Separate critics own receipts only, no production code. Scores/status only recorded by integrator from independent receipts.
