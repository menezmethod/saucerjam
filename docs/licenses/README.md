# `docs/licenses/`

Staged licence texts. **Nothing in this folder is operative.**

The operative licence for SaucerJam is the one in [`../../LICENSE`](../../LICENSE) (MIT
today). Files here are kept in the repository so that a licence switch is a reviewable
commit rather than an improvised one, and so an attorney can review the exact text
without depending on network access. Staging a text grants nobody anything.
