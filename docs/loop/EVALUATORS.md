# SaucerJam v2 Evaluators

Each evaluator reports evidence, not confidence.

## Required gates

- **Gameplay:** movement, aiming, firing, collisions, death/respawn, and combat readability.
- **Controls/devices:** keyboard/mouse, touch joystick/fire, portrait/landscape, resize, iPhone/iPad-sized viewports, and low-resolution rendering.
- **Systems:** authoritative server behavior, malformed input rejection, reconnect, room isolation, and persistence.
- **Performance:** build size, render submissions, frame behavior, simulation cost, and network payloads where measurable.
- **Visual:** composition, silhouette, contrast, landmarks, effects hierarchy, and whether the result is recognizably SaucerJam.

## Review rule

The builder may self-review for speed. A fresh critic must review any change making a visual, feel, balance, or showcase claim. Critical regressions block acceptance regardless of score.
